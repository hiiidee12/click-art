---

### ✨ Features

- 🎯 **Expanding Concentric Circles** — Click to spawn vibrant, expanding rings with random color palettes
- 💥 **Particle Bursts** — Each click releases a shower of glowing particles in all directions
- 🖱️ **Mouse Trail** — Move your cursor to paint a smooth trailing light effect
- 🌑 **Dark Canvas** — Immersive dark background that makes every color pop
- 📱 **Touch-Friendly** — Works beautifully on mobile and tablet devices
- 🪶 **Zero Dependencies** — A single HTML file, no build tools, no frameworks

---

### 🕹️ How to Use

1. Open the [live demo](https://click-art-kappa.vercel.app) (or clone and open `index.html` in any browser)
2. **Click** anywhere on the canvas to create expanding circle art
3. **Move** your mouse to draw a luminous trail
4. **Tap** on mobile — fully touch-enabled
5. Each interaction generates unique, never-repeatable patterns

---

### 🛠️ Tech Stack

| Technology | Role |
|---|---|
| **HTML5** | Structure & full-viewport canvas |
| **CSS3** | Dark theme & zero-margin layout |
| **Vanilla JavaScript** | Animation loop, particle physics, interaction handling |
| **Canvas 2D API** | All rendering — circles, particles, trails |

No frameworks. No libraries. Just the web platform.
